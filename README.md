# DigiCard Lab

デジモンカード初心者向けの、カード検索・デッキ構築・分析支援Webアプリです。

カード図鑑からデッキを作成し、レベル構成や色、カード種類、平均コストなどを確認できます。  
進化ルート表示、カード画像ビューア、お気に入り、複数デッキ保存、共有コード、デッキ診断にも対応しています。

## 主な機能

- カード図鑑
- 高機能カード検索
- 検索結果の並び替え
- カード詳細表示
- カード画像の拡大表示
- お気に入りカード保存
- デッキ構築
- デッキ枚数管理
- デッキ分析
- 初心者向けデッキ診断
- 進化ルート表示
- 複数デッキの保存・読込
- JSON形式の出力・読込
- 共有コードの生成・コピー・読込

## 使用技術

## 起動方法

このアプリは `fetch()` を使用してカードデータを読み込むため、HTMLファイルを直接開くのではなく、ローカルサーバー経由で起動してください。

XAMPPを使用する場合：

1. プロジェクトを `htdocs` 内に配置
2. Apacheを起動
3. ブラウザで次の形式のURLを開く

```text
http://localhost/degicard-lab/

フォルダ構成
degicard-lab/
├── data/
│   └── cards.json
├── images/
│   └── cards/
├── index.html
├── style.css
├── script.js
└── README.md

カード画像
カード画像は images/cards/ に配置します。
カードIDと画像ファイル名を一致させてください。
images/cards/BT1-010.webp
images/cards/BT1-015.webp
画像が存在しない場合は、代替表示になります。

保存データ

次の情報はブラウザの localStorage に保存されます。

現在編集中のデッキ
お気に入りカード
保存済みの複数デッキ

ブラウザの保存データを削除すると、登録内容も削除されます。

デッキ共有

デッキ共有画面から共有コードを生成できます。

生成されたコードを別の端末へ送り、共有コード読込欄へ貼り付けることでデッキを復元できます。

デッキ診断について

現在の診断は、次の情報をもとにブラウザ内で判定しています。

デッキ枚数
レベル構成
使用色数
カード種類の比率
平均登場コスト
平均DP

実際の対戦結果やカード効果同士の完全な相性を保証するものではなく、初心者向けの構築目安として表示しています。
